# Calculator

A simple calculator built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Clear button
- Delete button
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Use the calculator.
